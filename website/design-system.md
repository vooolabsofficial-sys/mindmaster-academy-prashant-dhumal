# MindMaster Academy Design System
**Theme**: Ivy Academic Prestige  
**Project ID**: 9760634045571096180  

## Brand & Style
The design system establishes an atmosphere of intellectual distinction, academic rigor, and classical prestige tailored for an elite educational institution. It pairs the architectural authority of an Ivy League publication with the swift clarity of modern pedagogical software.

### Colors
- **Primary Navy**: `#0E1B3D`
- **Secondary / Action Royal Blue**: `#0054CD` / `#0B57D0`
- **Surface**: `#F8F9FF`
- **Background**: `#F8F9FF`
- **Surface Container Lowest**: `#FFFFFF`
- **Surface Container**: `#EBEEF6`
- **Hairline Border**: `#E4E8F8` / `#C6C6CF`
- **Text Primary (On-Surface)**: `#181C21`
- **Text Secondary (Body Slate)**: `#5A6478`
